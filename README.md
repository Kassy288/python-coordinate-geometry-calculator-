# Coordinate Geometry Calculator

A Python program I created to perform common 3D coordinate geometry calculations.

## Features

- Calculates the midpoint between two 3D points
- Calculates the distance between two points
- Calculates the magnitude of a point's position vector
- Calculates the unit vector of a nonzero vector

## How to Run

1. Install Python or use a Python IDE such as Pydroid 3.
2. Open `coordinate_calculator.py`.
3. Run the program.
4. Enter the coordinates when prompted.
5. Choose the operation from the menu.

## Mathematical Formulas

### Midpoint

For points P1 and P2:

M = ((x1 + x2)/2, (y1 + y2)/2, (z1 + z2)/2)

### Distance

d = sqrt((x2 - x1)^2 + (y2 - y1)^2 + (z2 - z1)^2)

### Magnitude

|P| = sqrt(x^2 + y^2 + z^2)

### Unit Vector

A_hat = (x/|A|, y/|A|, z/|A|)

A zero vector has no defined unit vector.
